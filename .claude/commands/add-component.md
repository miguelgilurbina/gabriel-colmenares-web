Create a new React component following the project's patterns:
1. Ask for component name and purpose
2. Create the component file in `src/components/` with:
   - TypeScript with proper types
   - Framer Motion animations (containerVariants + itemVariants)
   - Tailwind CSS styling matching the brand colors (gabriel-blue, gabriel-yellow, gabriel-dark, gabriel-gray)
   - Lucide React icons if needed
   - Responsive design (mobile-first)
3. Add TypeScript interface in `src/lib/types.ts`
4. Update template.json if the component needs data
5. Show how to integrate it into the page

Follow existing component patterns from Hero.tsx, Shows.tsx, and Contact.tsx.
